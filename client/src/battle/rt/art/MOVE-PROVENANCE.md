# Original fire projectile sprite

Generated on 16 October 2026 with the built-in image tool, with actual transparent alpha and no reference art. Four frames in a 2 × 2 sheet. Original PNG: 1304 × 1206 pixels. Runtime lossless WebP: 652 × 604 pixels, nearest-neighbour reduction for screen use. Alpha was inspected independently: all four frames have transparent outer edges at alpha > 32. The bright-core centre of each frame was measured from its opaque cream pixels and stored as a separate anchor, avoiding movement caused by differing generated padding. The image is embedded inside move-art.js, including in exported playable pages. The loop uses the renderer clock, so pausing/restarting a replay also pauses/restarts this art. Projectile physics remain in the existing simulator.
