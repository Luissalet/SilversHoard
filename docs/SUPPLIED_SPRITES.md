# Supplied sprites

Silver bundles 447 sprite entries from 153 source files in Luis's `Sprites for Silvers` collection. The input inventory, original filenames, SHA256 hashes, ripping credits and exact crop rectangles are in `silvers_hoard/presets/supplied_sprites.json`. No input files are modified. Rebuild with Pillow and `python scripts/build_supplied_sprites.py <folder>`; runtime use needs no source folder, internet or game installation.

- All 18 navigation entries use Platinum menu icons or relevant contest/base sprites.
- Contests have 117 accessories, including the ten original choices. Search works in English and Spanish; selected art previews immediately and survives normal save/resume. Additional accessories use Silver's existing category/theme scoring, not cartridge accessory scores.
- Bases have 276 choices. These include every one of the 138 Generation IV goods supplied as individual PNGs, 37 older dolls, Emerald furniture, 64 numbered berry plants, three statues, five Rotom appliances and seven ball displays. The 138 supplied goods preserve their exact original PNG bytes. Their placement footprints follow the linked Generation IV list, including the 2x3 bed, 3x3 tables, 3x1 planter and 2x2 Magnezone doll. Named large objects reserve their full rectangular footprint for bounds, overlap, entrance/host and walking checks. Existing generic kinds and saved bases keep their historical one-cell footprints. Tools, holes, PCs and trophies are decorative replicas; cartridge traps, flag capture and rewards are not implemented. Berry numbers identify sheet variants. Search, place/erase, keyboard visits, host battles, JSON sharing, archive and restore use the normal handlers.
- The existing pixel particle style adds 18 Explorers of Sky projectile atlases and a Ranger impact atlas: 207 ordered animation frames. Fire, Water, Grass, Ice, Electric, Poison, Psychic, Ghost, Dark, Dragon, Rock, Ground, Flying, Bug, Fighting, Steel and Fairy receive type textures; the Normal star is reserved for Swift. Hits use the Ranger burst, including physical hits. The renderer uses its presentation clock and 12/16 fps, with fixed first frames under reduced motion. Ranger registration markers are removed. The original 17 Diamond/Pearl effect crops remain in the catalog. This is a curated visual mapping, not cartridge move choreography or every effect in the archives. Existing animation styles, plain particles and procedural layers remain available. Rules, RNG, inputs and damage never read the sprite catalog. Used assets are embedded into playable HTML and the video renderer.

`leisure_catalog(section, query, offset, limit)` is shared by UI, REST and MCP. Default pages contain 24 accessories/decorations; `section="sprites"` browses image/atlas metadata and stable PNG URLs, while `section="sources"` pages original source records. `pages.<section>.next_offset` reaches the next page. Search matches IDs, English/Spanish names, category and theme. `limit=0` explicitly requests all matches (the UI uses it); assistants should page to avoid the existing MCP response cap. Each page includes only the sources it references. `GET /api/sprites/supplied/{id}` returns exact embedded PNG bytes without network requests or mutable user cache.

Reference: <https://bulbapedia.bulbagarden.net/wiki/List_of_decoration_goods_in_Generation_IV>. Initial direct image requests returned HTTP 403; Luis subsequently supplied all 138 PNGs collected by Cursor in `Gen IV decoration goods`. The collection currently inventories 174 input files, including duplicates. Twenty input files remain unused; the importer does not claim every effect from their sheets or either archive. Source SHA256 hashes identify reused duplicate files. The generic lamp retains its existing vector fallback.

Game artwork remains © Nintendo, Creatures and GAME FREAK. Source sheets are not MIT artwork. Original ripping/editing credits are retained in the manifest and the app's Credits/API/MCP source list. Unknown individual authors are not invented.
