# Supplied sprites

Silver bundles 288 transparent crops from 13 of the 25 files in Luis's `Sprites for Silvers` collection. The complete input inventory, original filenames, SHA256 hashes, ripping credits and exact crop rectangles are in `silvers_hoard/presets/supplied_sprites.json`. No input files are modified. Rebuild with Pillow and `python scripts/build_supplied_sprites.py <folder>`; no internet or original game installation is needed at runtime.

- All 18 navigation entries use the supplied Platinum menu icons or relevant contest/base sprites.
- Contests have 117 accessories in total, including the ten original choices. The palettes can be searched in English or Spanish; selected art previews immediately and survives the normal contest save/resume. Additional accessories use Silver's existing category/theme scoring, not claimed cartridge accessory scores.
- Bases have 138 choices in total: original generic objects plus 37 dolls, Emerald furniture, 64 numbered berry plants, three statues, five Rotom appliances and seven ball displays. Named large objects reserve their full footprint, including walkability, bounds, overlap, entrance and host checks. Existing generic furniture and old saved bases retain their original one-cell footprints. Berry plant numbers identify sheet variants, not asserted botanical species. Search, click-to-place/erase, keyboard visits, host battles, JSON export/import, archive and restore use the normal handlers.
- The existing pixel particle style adds 17 embedded Fire, Ice, Ghost and Swift projectile frames in real-time and Silver-style classic battles. Other animation styles, plain particles, reduced motion and existing procedural effects retain their behavior. Rules, RNG, input logs and damage never read the sprite catalog. The same assets are embedded into playable HTML and used by the video renderer.

`leisure_catalog(section, query, offset, limit)` is shared by the UI, REST and MCP. Default pages contain 24 accessories/decorations; `section="sprites"` browses sprite metadata and stable PNG URLs. `pages.<section>.next_offset` reaches the next page. Search matches IDs, English/Spanish names, category and theme. `limit=0` explicitly requests all matches (the UI uses it); assistants should page to avoid the existing MCP response-size truncation. `GET /api/sprites/supplied/{id}` returns the exact crop bytes without network requests or mutable user cache.

The Bulbapedia Generation IV decoration list supplied by Luis was consulted for doll names and multi-cell decoration behavior: <https://bulbapedia.bulbagarden.net/wiki/List_of_decoration_goods_in_Generation_IV>. Direct image requests returned HTTP 403, so no Bulbapedia images were downloaded and no claim is made to reproduce its complete goods catalog. Twelve supplied files remain inventoried but unused, including the large Explorers of Sky attack archive; they are not presented as implemented animations. Three old generic objects retain their existing vector fallback where the supplied art does not match them.

Game artwork remains © Nintendo, Creatures and GAME FREAK. Source sheets are not MIT artwork. Original ripping credits are retained in the manifest and the app's normal Credits/API/MCP source list.
