# Supplied sprites

Silver bundles 783 sprite entries from 162 sources in Luis's `Sprites for Silvers` collection. The input inventory, original filenames, SHA256 hashes, ripping credits and exact crop rectangles are in `silvers_hoard/presets/supplied_sprites.json`. No input files are modified. Rebuild with Pillow and `python scripts/build_supplied_sprites.py <folder>`; runtime use needs no source folder, internet or game installation.

- All 18 navigation entries use Platinum menu icons or relevant contest/base sprites.
- Contests have 117 accessories, including the ten original choices. Search works in English and Spanish; selected art previews immediately and survives normal save/resume. Additional accessories use Silver's existing category/theme scoring, not cartridge accessory scores.
- Bases have 276 choices. These include every one of the 138 Generation IV goods supplied as individual PNGs, 37 older dolls, Emerald furniture, 64 numbered berry plants, three statues, five Rotom appliances and seven ball displays. The 138 supplied goods preserve their exact original PNG bytes. Their placement footprints follow the linked Generation IV list, including the 2x3 bed, 3x3 tables, 3x1 planter and 2x2 Magnezone doll. Named large objects reserve their full rectangular footprint for bounds, overlap, entrance/host and walking checks. Existing generic kinds and saved bases keep their historical one-cell footprints. Tools, holes, PCs and trophies are decorative replicas; cartridge traps, flag capture and rewards are not implemented. Berry numbers identify sheet variants. Search, place/erase, keyboard visits, host battles, JSON sharing, archive and restore use the normal handlers.
- The existing pixel particle style adds 28 supplied atlases with 253 ordered frames: 18 Explorers of Sky projectile atlases, one Ranger impact atlas, and nine GBA strips with 46 frames. Ember, Flame Burst, Pyro Ball, Thunder Shock, Power Gem, Ice Shard and Icicle Spear use specific GBA textures. Water Pulse/Bubble Beam/Aqua Jet impacts use water orbs; Aura Sphere/Dragon Pulse use blue pulses; Draining Kiss/Play Rough use hearts; Thunder Punch uses lightning. Other projectiles retain Sky type textures and other hits retain the Ranger burst. Swift keeps its specific star. The renderer uses its presentation clock and 12/16 fps, with fixed first frames under reduced motion. Ranger registration markers and the GBA palette backgrounds are removed, including the holes inside rings. The original 17 Diamond/Pearl effect crops remain in the catalog. This is a curated visual mapping, not cartridge move choreography or every effect in the archives. Existing animation styles, plain particles and procedural layers remain available. Rules, RNG, inputs and damage never read the sprite catalog. Used assets are embedded into playable HTML and the video renderer.
- Z-Move titles cover all 35 named Z-Moves in English and Spanish: 128 images, including the 29 Sun/Moon titles and 35 Ultra Sun/Ultra Moon titles per language. Choosing the existing Z-Move option previews the Sun/Moon artwork, falling back to Ultra titles for its six additional moves; names, type, category and PP stay visible. The actual move cue shows the Ultra title in the battle's displayed language, below the classic health boxes. It works with the existing Silver, Showdown and Reborn effect layers; disabling classic move effects also disables this decorative banner. Status moves such as Z-Growl retain their normal text. Real-time custom move events can display the same known title; this does not add a crystal/Z-Move mechanic or change their power. Titles keep their aspect ratio, clear on replay jumps and use the presentation clock; retimed classic effects keep the title readable without adding a wait or stopping the simulation. Reduced-motion real-time titles remain still. Artwork and readable text are separate; changing language never stretches or relabels an English image as Spanish.

`leisure_catalog(section, query, offset, limit)` is shared by UI, REST and MCP. Default pages contain 24 accessories/decorations; `section="sprites"` browses image/atlas metadata and stable PNG URLs, while `section="sources"` pages original source records. Title entries expose `move`, `lang` and `variant`; GBA atlases expose their original `frame_rects`. For example, `query="z-usum-es-"` finds the 35 Spanish Ultra titles. `pages.<section>.next_offset` reaches the next page. Search matches IDs, English/Spanish names, category and theme. `limit=0` explicitly requests all matches (the UI uses it); assistants should page to avoid the existing MCP response cap. Each page includes only the sources it references. `GET /api/sprites/supplied/{id}` returns exact embedded PNG bytes without network requests or mutable user cache.

Reference: <https://bulbapedia.bulbagarden.net/wiki/List_of_decoration_goods_in_Generation_IV>. Initial direct image requests returned HTTP 403; Luis subsequently supplied all 138 PNGs collected by Cursor in `Gen IV decoration goods`. The collection currently inventories 179 input files, including duplicates. Twelve input files remain unused; the importer does not claim every effect from their sheets or either archive. The supplied Ruby/Sapphire, Emerald and FireRed/LeafGreen Move Effects PNGs are byte-identical copies of Neslug's sheet and share one source record. Its original note says palettes may not be exact. Random Talking Bush is credited on the Z-title sheets. Source SHA256 hashes identify reused duplicate files. The generic lamp retains its existing vector fallback.

Game artwork remains © Nintendo, Creatures and GAME FREAK. Source sheets are not MIT artwork. Original ripping/editing credits are retained in the manifest and the app's Credits/API/MCP source list. Unknown individual authors are not invented.

## Real-time defaults and move coverage

RT and mass now render supplied material in all three particle preferences, including the default textured setting and plain particles. The classic pixel overlay described above remains unchanged. The manifest contains 227 atlases and 2836 frames, including20 single-texture resources. The original584 entries remain exact. An additional151 Sky sequences provide flames, waves, leaves, snow, rocks, tornadoes, poison, psychic/ghost/dark/dragon effects, webs, hearts, sound, healing and boosts.20 Black textures add actual fists, feet, teeth, slashes, feathers, rocks, hearts, rings, swirls, shields, cracks, waves, webs, snowflakes, notes, roots, gears, lightning, water and fire.

938 unique installed move IDs have a profile for preparation/travel/impact/area/contact. The renderer uses each role when that move actually has the corresponding event/shape. Named mappings and punch/bite/slicing flags take precedence over type families; dynamic public types handle Weather Ball and Hidden Power. Unsupported mechanical moves are marked available=false and receive no invented damage effect. These are composed RT visuals using genuine source material, not exact cartridge emitter programs or a claim that every move has unique art. Twelve local inventoried files remain unused; the new remote source is separate from the179-file local inventory.

Reproduce after the original manifest build with `python scripts/build_rt_particle_sprites.py "<supplied folder>/attacks" [--pokeblack <NARC>]` then `python scripts/build_rt_status_sprites.py "<supplied folder>"` then `python scripts/build_dragon_poison_sprites.py "<supplied folder>"` and `node scripts/build_rt_effect_profiles.mjs`. The optional download is pinned to [squiddonaut/pokeblack67d91a78](https://github.com/squiddonaut/pokeblack/tree/67d91a78b16caccbd4fbecdddf8a74c823d208a6), files/a/0/0/6, SHA256 `10cd758c77cbc275daf58e728e5e201907427f2491d2d3459c9988682d649e68`. The NARC has733 SPL resources; the conversion selects20 inspected textures and preserves their member/texture indices. The independent converter follows the [pret SPLTextureResource layout](https://github.com/pret/pokeheartgold/blob/master/lib/spl/include/spl_texture.h); no decompilation code is executed or required at runtime. Art remains copyright Nintendo/Creatures/Game Freak; the repo does not confer MIT on those pixels. Source hash, revision and original authors are in the manifest and Credits.

## Specific motifs and PMD states

The second RT pass adds 100 inspected Sky sequences and eight Red Rescue Team status rows (78 frames). 386 available move IDs now select a named motif (117 before this pass): swords/gears/coins/bones/petals/sludge/meteors, distinct water/ice/electric/psychic motifs and several support moves. Self buffs can orbit their real user, spirals fill the actual area, coins and meteors fall, and Tri Attack has a three-part head. Art can be shared by related moves; this count is not a count of unique choreography. 467 available IDs still use type families, and 85 IDs have no mechanical RT effect.

The exact supplied PMD status sheet provides flames, sparks, an ice block, skulls, Zs, question marks, crosses and shields. The renderer reads burn, paralysis, freeze, poison/toxic and sleep/drowsiness from the active mon; confusion, taunt and protect from its unit. The RT sleep rule remains drowsiness. Poison and toxic share the original skull row. A cure, slot change, faint, end or replay seek changes the next drawn frame immediately; pause freezes animation and reduced motion selects frame zero. There is no event-based substitute for a status actually present. Singles/doubles and visible mass units use the same atlas layer with no pixel preference required. Status rows retain fixed cells, transparency and the supplied pixels. Credits identify the original game; the sheet itself does not identify its ripper.

The `effects` native catalog includes `status_effects`, referencing those exact PNG endpoints and their manifest source. Rebuild in order: base supplied sprites, RT particles, RT status rows, local Dragon/Poison motifs, local Rock motifs, then move profiles. None of these build steps writes to the original sprite directory.
