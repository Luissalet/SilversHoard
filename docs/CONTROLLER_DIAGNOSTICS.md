# Controller diagnostics

Open Settings and expand Controller diagnostics. Connect a controller, press a button to let the browser discover it, then start sampling. The selected controller's axes show values from -1 to 1; every button shows its analog value (0 to 1), pressed and touched states. B6/B7 are the triggers on a standard browser mapping. Nonstandard mappings are identified explicitly. The display can select one controller while the local log records all connected devices.

The guide covers the current handlers for real time (Z-A or simple), mass battles (simple, only movement/moves/roll are consumed), gym maps, Pokéathlon (event-dependent controls, with concrete examples) and Arcade roulette. Selecting a mode labels the log and changes the help; it does not remap the controller or launch a game. The single catalog is returned by `controller_guide`, available through the existing UI/REST/MCP routes. Source paths for each mode are included for assistants. MCP cannot read a controller connected to a browser.

Only changed readings are logged, at three decimal places, together with mode/layout, start/stop and visibility changes. A disconnect appears as an input sample without that device. There are at most 2048 entries; reaching the limit stops sampling until the log is cleared. Stop and resume retain the same session, collapsing the panel stops sampling, and navigating away cancels polling. Background tabs pause reading. Clear is disabled while sampling. Nothing is sent or saved automatically: download the JSON before leaving. It contains browser-provided controller IDs; review it before sharing. A session with no connected controller records an empty device list, never fabricated presses.

Gamepad availability depends on browser support, a secure context (HTTPS or localhost), permissions and device discovery after interaction. Unsupported or blocked access is reported with recovery instructions. No physical-controller claim is made when the browser detects none. Synthetic Node fixtures test raw analog readings, press/release/disconnect, mode labels, bounded exports, both language catalogs and the documented Z-A/simple bindings against the real `SeatInput` handler.

Connection help displays a PowerShell `New-NetFirewallRule` command for Silver's configured web port, scoped to the Private profile and LocalSubnet. It is text only, never executed. Local controllers do not need an open port. A firewall rule does not change Silver's listening address or open its separate room server port. The normal host/network setup still applies; this feature creates no server and changes no system settings.
