# Standalone presentation assets

New trainer, gym, weekly, daily and mass HTML exports include the already cached Pokémon/trainer sprites, Showdown effect pictures/backdrops and allowed Reborn animation files, sheets and sounds. Export reads these presentation caches without fetching, modifying them or copying personal libraries. Assets are embedded once, with URL aliases referring to the same bytes. The response exposes `embedded_assets` through the existing UI/REST/MCP export handlers.

The standalone runtime resolves presentation URLs before an image, sound or fetch starts. Missing Pokémon art becomes a local labelled disc; a cached static sprite is preferred when its animated variant is absent. Missing decorative images remain transparent. A missing Reborn animation keeps Silver's existing fallback. Supplied art, procedural effects and generated sound remain embedded as before. No API keys, remote API, source collection or running Silver installation is needed to play an exported challenge.

Exports include the presentation cache available when created, so HTML size grows with that cache. Later downloads do not change an already exported file. A challenger species with no included picture uses its local placeholder. These pages retain the existing limitation that ordinary cries and music are not embedded; Reborn's cached move sounds are included. Walking overworld sprites already exported by Silver remain embedded. This change does not add multiplayer or alter the app's existing live-room protocol, battle rules, seeds or result verification. Old files contain their old bundled runtime; re-export to obtain this behavior.
