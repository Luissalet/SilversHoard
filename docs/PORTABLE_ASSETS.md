# Standalone presentation assets

New trainer, gym, weekly, daily and mass HTML exports include the installed PMD library plus already cached Pokémon/trainer sprites, Showdown effect pictures/backdrops and allowed Reborn animation files, sheets and sounds. Export reads the installed collection and presentation caches without fetching, modifying them or copying personal libraries. Assets are embedded once, with URL aliases referring to the same bytes. The response exposes `embedded_assets` through the existing UI/REST/MCP export handlers.

The standalone runtime resolves presentation URLs before an image, sound or fetch starts. Available PMD bodies and front/back previews resolve from an exact species/form index independently of the user's cache. Compressed binary packs sit outside the share-code JSON and decode lazily to Blob slices. Pikachu-Gmax remains unresolved in the current reviewed collection; it and unsupported custom identities retain the existing static/labelled fallback. Missing decorative images remain transparent. A missing Reborn animation keeps Silver's existing fallback. Supplied art, procedural effects and generated sound remain embedded as before. No API keys, remote API, source collection or running Silver installation is needed to play an exported challenge.

HTML size includes the installed PMD collection and grows further with the presentation cache available at export. Later library updates/downloads do not change an existing file. These pages retain the existing limitation that ordinary cries and music are not embedded; Reborn's cached move sounds are included. Imported walking sprites remain embedded and keep their selection priority. Live rooms, battle rules, seeds and result verification retain their existing behavior. Old files contain their old bundled runtime; re-export to obtain this behavior. See [library provenance, coverage and rebuilding](PMD_LIBRARY.md).
