# Themed exercise packs

Save positions with the existing replay exercise controls, then open Share. Select exercises, enter a pack name and choose **Attrition wins**, **Opening matchups** or **Doubles positioning**. The selection order is the order in the exported pack. These are editorial labels chosen by the curator, not automatic tactical classifications or proof of an optimal move or guaranteed win. They do not change exercise goals or restrict the formats that can be grouped.

`exercise_pack_export(ids, title, theme)` is the same handler used by UI, REST and MCP. It returns text and a downloadable `.silverexercise` file. The container has kind `silvers-hoard/exercise-pack`, schema1, a title, theme and an ordered `exercises` array of the unchanged schema1 `silvers-hoard/exercise` objects. Single-exercise export/import still uses its original format and extension. Repeated selected IDs appear once, in first-selected order.

Paste the pack or upload its file through normal Import. Every position is reconstructed with the existing engine before any exercise is saved; only canonical teams, format and the committed past prefix survive. Once validation finishes, the existing database transaction saves all exercises together. An invalid later position or a database error leaves no partial import. A fresh receiver needs no original replay or trainer. Imported exercises show the pack name, theme and position number, and keep the existing start, manual/adaptive difficulty, attempts, individual sharing and reversible archive actions.

No source replay IDs, exercise IDs, previous pack IDs, future decisions or attempts are exported. The initial teams are intentionally part of a portable position, as for individual exercises; this is not a hidden-team puzzle format. The receiving library assigns fresh identities and retains pack membership in existing exercise payloads, without a database migration or separate pack table. Export writes only the explicitly requested file. Import adds only exercises, and each attempt is the existing independent practice battle: no source replay changes, trainer records, badges or hall entries. It does not introduce a second simulator, model, automatic corpus curation or server.
