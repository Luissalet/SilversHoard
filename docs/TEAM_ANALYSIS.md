# Team analysis

Open a trainer's visual team editor, expand **Team analysis**, and choose **Analyse team**. The report uses the current draft without saving it. Editing a set or changing format hides the old report until it is recalculated. It works with the installed simulator and needs no Internet, model, remote dataset or additional package.

The same read-only `team_analysis` handler is available through UI, REST and MCP. Supply `team` (one to six set objects) or `paste` (Showdown, packed or JSON), a `format` (default `gen9nationaldexag`), and optional `level_rules` (`level`, `level_cap`, `level_min`). It returns all rows without the agent result cap. Unknown/future species and moves or invalid formats return normal input errors. Incomplete sets without moves can be analysed while drafting; this does not validate format legality.

## Reading the report

- **Defence:** every attacking type's multiplier against each member's written species types in the format's generation. Dual types multiply, immunities take precedence, and historical type charts apply. Shared weaknesses identify two or more members; counts refer to members, not moves. Abilities, held items, Tera, Mega Evolution from an item, weather and other battle effects do not alter this type-only table. For example, Rotom-Wash is shown as Ground-weak even with Levitate: use the damage calculator for ability-aware matchups.
- **Attack coverage:** each member's best ordinary damaging move multiplier against a hypothetical single-type opponent. A dash means no included moves. The final column counts members with super-effective coverage. The report includes the moves behind each covered type in its API/MCP output. It does not combine opponent dual types, STAB, power, accuracy or battle effects. Status moves do not contribute. Fixed/proportional damage, OHKO, variable-type moves (including Hidden Power), typeless Struggle and attacks with special effectiveness/immunities are excluded and disclosed by name/reason; Freeze-Dry and Flying Press therefore do not receive misleading ordinary-chart coverage.
- **Speed order:** the simulator's unmodified Speed for each set, including its generation's stat/DV rules, nature, EVs/IVs and the reported effective level. Champions' points conversion uses the existing team preparation. Items, abilities, status, boosts, Tailwind and Trick Room are excluded. Equal stats keep team order and do not predict which Pokémon moves first.

The report does not create battles or modify saved trainers, statistics, records, badges, settings or replays. It is a planning aid, not a win prediction or a damage calculator. Browser-safe `engine/src/team-analysis.mjs` computes it from the same installed Dex as the engine; `server.mjs` exposes its native command, and the ordinary `agent_tools.py` catalogue drives every transport. No simulator rule or replay version changes.
